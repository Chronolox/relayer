# Contributing to Chronolox Relayer

This repository manages binary release verification, platform builds, appliance ISO checksums, and signing key distribution for Chronolox Relayer.

## How to Contribute

- **Platform Testing:** Verify `chronolox-relayer` or the appliance ISO on untested distributions or hypervisors.
- **Verification Tooling:** Propose improvements to checksum verification scripts or deployment templates.
- **Reporting Issues:**
  - For suspected corrupted archives or checksum discrepancies, open an [issue](https://github.com/Chronolox/relayer/issues).
  - For security vulnerabilities, do NOT open a public issue. Follow [SECURITY.md](./SECURITY.md) and email `security@chronolox.com`.
